# Kalles Waldspaziergang

3D-Endlosläufer im Comic-Stil mit Kalle, dem Jack-Russell-Golden-Mix.

**Spielen:** https://mkp4dmh8vz-bot.github.io/kalle-/

Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

- `index.html` – das komplette Spiel (eine Datei, läuft ohne Nachladen)
- `apple-touch-icon.png`, `icon-512.png` – App-Symbol
- `manifest.webmanifest` – App-Name und Vollbild-Einstellung
